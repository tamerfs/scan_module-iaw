# ECU K-Line / IAW Diagnostic Project

Projeto de engenharia reversa e desenvolvimento de diagnóstico para ECU Fiat via K-Line.

## Estrutura

- `docs/PROJECT.md` — documentação consolidada.
- `docs/HARDWARE.md` — hardware, conectores e medições.
- `docs/PROTOCOL.md` — protocolo K-Line e frames.
- `docs/TESTS.md` — testes e resultados.
- `docs/EVIDENCE.md` — evidências e fontes.
- `docs/agents/` — contribuições de cada IA.
- `data/captures/` — capturas estruturadas JSONL.
- `data/raw/` — dados brutos.
- `data/decoded/` — dados interpretados.
- `src/` — código Python.

## Regra

Evidência bruta deve ser preservada. Hipóteses não devem ser registradas como fatos.
