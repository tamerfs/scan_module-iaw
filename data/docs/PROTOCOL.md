# K-Line / Protocolo

Documento para consolidar o protocolo somente após evidências.

Registrar, quando conhecido:

- baudrate;
- parity;
- stop bits;
- inicialização;
- wake-up;
- header;
- source;
- target;
- command;
- data;
- checksum;
- timing;
- respostas;
- erros.

Toda interpretação deve indicar confiança: Alta, Média ou Baixa.
